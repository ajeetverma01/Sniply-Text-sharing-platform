# Sniply

A simple text and code sharing platform.

## About

Sniply lets users paste text or code, generate a unique shareable link, and access the content through that link.

## Features

- Create text and code snippets
- Generate unique shareable links
- View shared content
- Store snippets in PostgreSQL

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Maven
