# Sniply

A simple way to share text and code snippets with a link.

Sniply is a small full-stack project I built to make sharing text and code easier. Paste your content, create a unique link, and share it with anyone who needs it.

## Live Demo

Try Sniply : **[https://sniply-beta.vercel.app/](https://sniply-beta.vercel.app/)**

## Features

- Create and share text or code snippets
- Generate unique links for every paste
- View snippets directly through their shareable URLs
- Set an optional expiration time for pastes
- Automatically clean up expired pastes
- Store snippet data in PostgreSQL

## Tech Stack

**Backend**
- Java

**Frontend**
- React
- Vite

**Database & Deployment**
- PostgreSQL
- Docker
- Neon
- Render
- Vercel


## Why I Built This

I wanted to build something practical while learning Java and Spring Boot. Sniply gave me an another chance to work with REST APIs, database integration, validation, expiration logic, and deployment.

It's a learning project, and there's still room to improve.
